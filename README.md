### [AI-DLC &amp; Spec-Driven SDLC Alternatives (`aidlc/`)](aidlc/)

- **[Total Comparison Dashboard (`aidlc/comparison/`)](aidlc/comparison/)** — Side-by-side comparison of all 10 frameworks across architecture, workflow, ceremony, speed vs governance, greenfield vs brownfield, spec drift, human bottleneck, head-to-head picker, and 2D landscape quadrant map.
- **[Interactive Evaluation &amp; Fit Recommender (`aidlc/evaluation/`)](aidlc/evaluation/)** — Weighted scoring matrix (7 priority sliders + 6 team presets) dynamically ranking all 10 frameworks.

  3. **[BMAD Method (`aidlc/bmad/`)](aidlc/bmad/)** — Scale-adaptive multi-agent agile workflow with 21+ role personas.
  4. **[OpenSpec (`aidlc/openspec/`)](aidlc/openspec/)** — Fluid brownfield-first delta specs across 25–30+ AI tools.
  5. **[Anthropic AI-Native SDLC (`aidlc/anthropic-sdlc/`)](aidlc/anthropic-sdlc/)** — Enterprise governance playbook with separation of duties & Git-committed `intent.md`.
  6. **[Cursor pstack (`aidlc/cursor-pstack/`)](aidlc/cursor-pstack/)** — High-speed parallel agent playbooks (`/tdd`, `/swarm`, `/code-review`) + automated verifier agents.
  7. **[Tessl (`aidlc/tessl/`)](aidlc/tessl/)** — Spec-as-source framework with continuous CI/CD test synchronization.
  8. **[specs.md (`aidlc/specs-md/`)](aidlc/specs-md/)** — Lighter AI-DLC flows (FIRE adaptive 0–2 checkpoints & Simple 3-phase) + VS Code dashboard.
  9. **[Kiro Native Specs (`aidlc/kiro-specs/`)](aidlc/kiro-specs/)** — IDE-native 3-file spec workflow with formal EARS requirements, Steering Docs, and Agent Hooks.
  10. **[Superpowers / Obra (`aidlc/superpowers/`)](aidlc/superpowers/)** — Composable senior-engineer skills (Brainstorming, Plans, Git Worktrees, Fresh Subagent TDD, Two-Stage Review, Verification).
