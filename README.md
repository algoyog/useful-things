# useful-things

A curated collection of visual guides, first-principles explainers, papers, and reference artifacts.

## Contents

### [AI-DLC (`aidlc/`)](aidlc/)
Interactive visual understander and complete first-principles reference for the **AI-Driven Development Lifecycle (AI-DLC)** — combining Raja SP's Method Definition Paper (AWS) with the [`awslabs/aidlc-workflows`](https://github.com/awslabs/aidlc-workflows) v2.11.4 multi-harness implementation.

- **[Interactive Visual Guide (`aidlc/index.html`)](aidlc/index.html)** — 100% offline-capable HTML guide with interactive SVG mind map, live search, Dark/Light mode, first principles, 10 paper principles, Agile-to-AI-DLC translator, 5 phases / 33 stages, 11 scopes, 14 agents, 6 sensors, 17 hooks, 5 fences, and 7 harnesses.
- **[AI-DLC Method Definition Paper (PDF)](aidlc/assets/AI-DLC-Method-Definition-Paper.pdf)** — Original 8-page paper by Raja SP, Amazon Web Services.
- **[AI-DLC Workflows 2.0 Specification (PDF)](aidlc/assets/AI-DLC-Workflows-2.0-Specification.pdf)** — Architecture and methodology specification.
- **[Reference Docs (`aidlc/reference/`)](aidlc/reference/)** — Glossary, Introduction, Phases & Stages, Workflow Profiles, and 3-Plane Architecture.
