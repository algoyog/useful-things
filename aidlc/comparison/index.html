Quick Decision Trade-off Rules

If human review is slowing you down: Move from AWS AI-DLC to OpenSpec (lightweight delta reviews), specs.md FIRE (0–2 adaptive gates), or Cursor pstack (automated verifier agents).
If specs go stale right after launch: Choose OpenSpec (merges deltas back into a living spec) or Tessl (binds specs directly to automated CI builds & tests).
If you need enterprise compliance without 33 stages: Choose Anthropic AI-Native SDLC (separation of duties + Git intent.md) or GitHub Spec Kit (portable standard).
If you want TDD craft or IDE-native simplicity: Choose Superpowers (strict TDD, worktrees, fresh subagents) or Kiro Native Specs (3-file EARS specs built right into Kiro IDE).
